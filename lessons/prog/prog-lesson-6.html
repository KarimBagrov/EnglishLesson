Урок 6 · React: Основы

Компоненты, props, state и хуки — фундамент современного фронтенда

JUNIOR · 2026 · ≈ 100 МИН

1 Введение: что такое React

Представь, что ты строишь дом из LEGO. В обычном JavaScript ты бы каждый раз собирал дом с нуля, если захочешь поменять одну деталь. React позволяет собирать дом из компонентов (кирпичиков). Если нужно поменять окно, ты меняешь только компонент «Окно», а не весь дом.

React — это библиотека, которая помогает описывать интерфейс как набор компонентов. Когда данные меняются, React автоматически обновляет только нужные части страницы (это называется Virtual DOM).

💡 Главная мысль: В React мы не ищем элементы на странице (document.getElementById), мы описываем, как интерфейс должен выглядеть при определенных данных, а React сам делает так, чтобы страница выглядела именно так.

2 Компоненты

Компонент — это функция, которая возвращает JSX (разметку, похожую на HTML). Имя компонента всегда пишется с большой буквы.

function Welcome() {
return <h1>Привет, мир!</h1>;
}

Компоненты можно вкладывать друг в друга, как матрешку.

3 Props (входные данные)

Props (сокращение от properties) — это данные, которые передаются в компонент извне. Это как аргументы функции.

3.1. Пример

function UserCard(props) {
return <div>Привет, {props.name}</div>;
}
// Использование:
<UserCard name="Иван" />

Props нельзя изменять внутри компонента. Они только для чтения. Если нужно, чтобы данные менялись, используется state.

4 State и useState

State — это внутреннее состояние компонента. Если props — это то, что пришло снаружи, то state — это то, что компонент «помнит» и может менять.

Для создания состояния используется хук useState.

import { useState } from 'react';
function Counter() {
const [count, setCount] = useState(0);
return (
<div>
<p>Вы нажали {count} раз</p>
<button onClick={() => setCount(count + 1)}>Нажми меня</button>
</div>
);
}

Как это читать: count — текущее значение, setCount — функция для его изменения. Начальное значение — 0. Когда мы вызываем setCount, React перерисовывает компонент с новым значением.

5 useEffect (побочные эффекты)

useEffect используется для побочных эффектов: запросов к серверу, подписок, работы с DOM. Он запускается после того, как компонент отрисовался.

import { useEffect, useState } from 'react';
function DataFetcher() {
const [data, setData] = useState(null);
useEffect(() => {
fetch('https://api.example.com/data')
.then(res => res.json())
.then(data => setData(data));
}, []); // Пустой массив означает: выполнить один раз при монтировании
return <div>{data ? data.name : 'Загрузка...'}</div>;
}

Пустой массив [] в конце означает, что эффект выполнится только один раз (как componentDidMount в старом React). Если убрать массив, эффект будет выполняться после каждой перерисовки.

6 Как спросят на собеседовании

Вопрос: В чем разница между props и state?

Ответ: «Props передаются в компонент снаружи и доступны только для чтения. State — это внутреннее состояние компонента, которое он может менять с помощью setState (или useState). Изменение state вызывает перерисовку компонента.»

Вопрос: Что делает useEffect?

Ответ: «useEffect используется для побочных эффектов: запросов к API, подписок, работы с таймерами. Он принимает функцию и массив зависимостей. Если массив пустой — эффект срабатывает один раз при монтировании. Если в массиве есть значения — эффект срабатывает при их изменении.»

7 Типичные ошибки

Ошибка 1: Мутировать state напрямую

❌ count = count + 1;
React не узнает об изменении и не перерисует компонент.
✅ setCount(count + 1);

Ошибка 2: Забыть зависимости в useEffect

❌ useEffect(() => { fetchData(id); }, []); // id не в зависимостях
Если id изменится, данные не обновятся.
✅ useEffect(() => { fetchData(id); }, [id]);
