Урок 4 · Современный JavaScript

Деструктуризация, spread/rest, optional chaining — фишки, без которых ваш код будет выглядеть устаревшим

JUNIOR · 2026 · ≈ 80 МИН

1 Введение: зачем это нужно

Раньше код на JavaScript был громоздким. Чтобы достать значение из объекта, приходилось писать длинные цепочки, а чтобы скопировать массив — использовать циклы. С 2015 года (ES6) и далее язык сильно изменился. Появились «синтаксический сахар» — короткие и удобные конструкции, которые делают код читаемее.

На собеседовании junior-разработчика спрашивают про эти фишки, чтобы проверить, пишете ли вы современный код или застряли в 2010 году.

💡 Главная мысль: Современный JavaScript — это не про то, чтобы учить больше команд, а про то, чтобы писать меньше кода и делать его понятнее для коллег.

2 Деструктуризация

Деструктуризация — это когда мы «разбираем» объект или массив на отдельные переменные. Вместо того чтобы писать user.name и user.age, мы можем сразу вытащить их в переменные.

2.1. Деструктуризация объектов

const user = { name: "Иван", age: 25 };
// Старый способ:
const name = user.name;
const age = user.age;
// Современный способ (деструктуризация):
const { name, age } = user;
console.log(name); // "Иван"
console.log(age); // 25

2.2. Деструктуризация массивов

const colors = ["красный", "синий", "зеленый"];
const [first, second] = colors;
console.log(first); // "красный"
console.log(second); // "синий"

2.3. Переименование

Иногда имя переменной не совпадает с именем свойства. Тогда можно переименовать:

const { name: userName } = user;
console.log(userName); // "Иван"

3 Spread и Rest (...)

Три точки ... в JavaScript могут значить две разные вещи в зависимости от контекста: spread (развернуть) и rest (собрать).

3.1. Spread (развернуть)

Используется, чтобы скопировать массив или объект или объединить их. Это как высыпать содержимое одной коробки в другую.

const arr1 = [1, 2, 3];
const arr2 = [...arr1, 4, 5]; // [1, 2, 3, 4, 5]
// То же самое с объектами:
const user = { name: "Иван" };
const updatedUser = { ...user, age: 25 }; // { name: "Иван", age: 25 }

3.2. Rest (собрать)

Используется в параметрах функции, чтобы собрать все оставшиеся аргументы в массив.

function sum(...numbers) {
return numbers.reduce((acc, num) => acc + num, 0);
}
console.log(sum(1, 2, 3, 4)); // 10

4 Optional Chaining (?.)

Представь, что у тебя есть данные с сервера, и ты хочешь достать оттуда имя пользователя. Но пользователь может быть null (например, он ещё не вошел). Если ты напишешь user.name, а user равен null, программа упадет с ошибкой.

Optional chaining (?.) позволяет безопасно обратиться к свойству: если объект null или undefined, он просто вернет undefined, а не упадет.

const user = null;
// Ошибка! TypeError: Cannot read properties of null (reading 'name')
console.log(user.name);
// Безопасно: вернет undefined
console.log(user?.name);

Это работает и для вызовов функций: user?.getName?.().

5 Nullish Coalescing (??)

Этот оператор (??) возвращает правую часть, только если левая равна null или undefined. В остальных случаях (даже если это 0 или "") он возвращает левую часть.

Раньше для этого использовали || (логическое ИЛИ), но у него есть проблема: он считает 0 и "" «ложными» и заменяет их.

const count = 0;
console.log(count || 10); // 10 (потому что 0 — falsy)
console.log(count ?? 10); // 0 (потому что 0 — это не null и не undefined)

Оператор ?? намного безопаснее для установки значений по умолчанию, когда 0 или пустая строка — это валидные значения.

6 Как спросят на собеседовании

Вопрос: Чем ?? отличается от ||?

Ответ: «Оператор || возвращает правое значение, если левое — любое falsy-значение (включая 0, пустую строку, false). Оператор ?? возвращает правое значение только если левое — null или undefined. Поэтому для значений по умолчанию, когда 0 или пустая строка важны, лучше использовать ??.»

7 Типичные ошибки

Ошибка 1: Использование || вместо ?? для чисел

❌ const price = 0 || 100; // 100 (неправильно, если 0 — валидная цена)
✅ const price = 0 ?? 100; // 0 (правильно)

Ошибка 2: Забыли ?. и получили ошибку

❌ const name = user.profile.name; // ошибка, если user или profile — null
✅ const name = user?.profile?.name;

Задание 2

Что выведет этот код?

const x = 0; console.log(x ?? 5); console.log(x || 5);
Показать ответ0 и 5. Потому что ?? видит, что 0 — это не null/undefined, и оставляет 0. А || считает 0 ложным и возвращает 5.
